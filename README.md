# Sistema de cotizaciones PERSEVI

Aplicación web de cotizaciones desarrollada con PHP nativo, HTML, CSS, JavaScript y MySQL/MariaDB.

## Requisitos locales
- PHP 8.2 o compatible
- Apache
- MySQL/MariaDB
- Composer (para dependencias, como Dompdf)

## Inicio
1. Colocar la carpeta dentro de `C:\xampp\htdocs\`.
2. Iniciar Apache desde XAMPP.
3. Abrir `http://localhost/cotizacion-persevi/`.

## Seguridad
No subir contraseñas ni archivos de configuración con credenciales al repositorio.
